How I work

Both reports are generated by Python scripts that write the Power BI project (PBIP): the model in TMDL and the report in PBIR. Every rule is versioned, and the same logic works for any store in the network.

Only data that existsWhen the base is missing, the card says why instead of showing zero.
Written rulesEvery measure has a description, and the measure dictionary comes from the model itself.
Code and hand togetherLayout tweaks made in Desktop are captured and reapplied in every new version.
Cross-checked sourcesWhen the same number lives in two places, the report shows the difference, by day and by store.
